WHAT WAS IMPLEMENTED
---------------------
A new page at the route /top-categories that shows all expense categories
ranked by total amount spent, highest first. For each category it shows:
  - rank (1, 2, 3, ...)
  - category name with its CATEGORY_COLORS swatch
  - number of expenses in that category
  - total $ spent in that category (formatted via lib/format.ts formatCurrency)
  - % of overall spend (computed against the sum of all category totals)

The page renders two Card sections:
  1. A horizontal recharts BarChart (one bar per category, sorted
     descending by total, colored per CATEGORY_COLORS) inside a Card,
     with a header line showing overall total $ and category count.
  2. A ranked breakdown list (rank badge, color dot, category name,
     expense count, $ total, % share, and a proportional progress bar)
     below the chart, in a second Card.

Empty state: if there are no expenses at all, the page shows a centered
"No spending data yet" message (same visual pattern used by the existing
Dashboard empty state) instead of the chart/list.

Loading state: mirrors app/page.tsx's existing spinner/"Loading your
expenses..." treatment while useExpenses() has not yet loaded from
localStorage (isLoaded === false), to avoid a flash of an empty state.

A small header on the new page includes a logo (linking back to "/")
and a "← Back to Dashboard" link.

FILES CREATED
-------------
- app/top-categories/page.tsx
    New client-component route ("use client"). Calls useExpenses()
    directly (this page is a route, not a components/ domain
    component, so this doesn't violate the existing convention that
    components/ domain components receive expenses via props rather
    than calling the hook themselves). Aggregates expenses by category
    with useMemo, sorts descending by total, and renders the
    chart + list inside Cards, plus loading/empty states.

- components/analytics/TopCategoriesChart.tsx
    Recharts horizontal BarChart component. Exports TopCategoryDatum
    type ({ category, total, count }) consumed by both the chart and
    the list. Bars colored via CATEGORY_COLORS[category], height scales
    with number of categories. X axis ticks formatted with
    formatCurrency; tooltip also formatted with formatCurrency.

- components/analytics/TopCategoriesList.tsx
    Ranked <ol> list: rank badge, color dot + category name, expense
    count, formatCurrency(total), % share, and a colored proportional
    bar underneath each row — styled consistently with the existing
    CategoryBreakdownChart's list half (components/analytics/
    CategoryBreakdownChart.tsx) so it matches the app's established
    visual language for category breakdowns.
