WHAT WAS IMPLEMENTED
---------------------
A new "Top Vendors" page that groups all expenses by vendor and ranks them by
total amount spent (highest first). Since the Expense data model has no
dedicated "vendor" field, the (trimmed) `description` field is used as the
vendor/merchant name — this was an explicit, deliberate simplification per
task instructions, not an oversight.

The page (app/top-vendors/page.tsx) has:
- A loading state matching app/page.tsx's spinner (waits on useExpenses()'s
  `isLoaded` flag before rendering, to avoid a flash of "no data" before
  localStorage is read).
- An empty state ("No spending data yet") when there are zero expenses.
- A recharts horizontal BarChart showing the top 10 vendors by total spend
  (styled consistently with the existing analytics charts in
  components/analytics/*.tsx — same axis/tooltip/grid conventions, indigo
  #6366f1 bar color matching the existing SpendingTrendChart).
- A full ranked list ("All Vendors") below the chart showing, per vendor:
  rank, vendor name, expense count, total $ (via lib/format.ts's
  formatCurrency), and % of overall spend.
- Blank/whitespace-only descriptions are bucketed into a synthetic "Unknown"
  vendor bucket rather than crashing or rendering a blank row.
- A "Back" link at the top returns to the main "/" route.

Aggregation logic (grouping, summing, computing share of total, sorting
descending by total) lives inline in the page component via useMemo — kept
local to this page rather than added to the shared lib/analytics.ts, both
because the feature is intentionally simple/self-contained and to avoid
touching a shared file that increases merge-conflict surface with the
concurrent "Top Expense Categories" work (see Integration Notes below).
